# Roadmap «доделать проект» — карта остатков и порядок работ

**Дата:** 2026-06-02
**Статус:** согласовано (декомпозиция), под-проекты стартуют по spec-first (§8)
**Назначение:** единая карта всего, что осталось сделать в `lk-otsfera`, с порядком, зависимостями, оценками и **готовыми промтами** для запуска каждого под-проекта.

> Это не план реализации с чекбоксами, а **декомпозиция верхнего уровня**. Каждый нетривиальный под-проект ниже получает свой собственный цикл `brainstorm → spec → plan → impl` (CLAUDE.md §8). Документ — «оглавление» этих циклов и ответ на вопрос «какой промт давать, чтобы доделать проект».

## 0. Где мы сейчас

Проект **feature-complete**, всё отгружено в `origin/main`:

- **4 кабинета**: partner / organization / manager / admin.
- **1С-sync-бэкбон**: курсор, zod-валидация, изоляция записей, идемпотентный push, shadow-режим, REST-скелет — построено, но работает на `FakeOneCAdapter` (`ONE_C_ADAPTER=fake`).

«Доделать» = закрыть **3 независимых трека** (A: 1С боевой, B: чат, C: бэклог-доработки).

## Рекомендуемая последовательность

Порядок диктуется **блокерами**, а не только ценностью: 1С самый ценный, но ждёт внешних ответов — значит запускаем его как встречу параллельно, не простаивая.

1. **Сейчас, параллельно (не занимает агента):** инициировать встречу 1С — **A1**.
2. **Эта сессия:** брейнсторм чата — **B1** (самый большой неизвестный, спеку надо двигать раньше всех).
3. **Быстрые внутренние победы (между делом, низкий риск):** **C3 → C4 → C5** — чистят фундамент перед тем, как класть на него чат.
4. **Паритет ролей:** **C1**, **C2**.
5. **Когда ответы 1С пришли:** **A2 → A3**.
6. **Финал:** **C6** (решения) + **C7** (staged rollout) — последний гейт перед «готово».

## Как пользоваться этим документом

- «Доделать проект» **нельзя одним промтом** — это 3 трека, каждый нетривиальный под-проект идёт через §8.
- Для **net-new** (чат, finance-хаб) первый промт — `/superpowers:brainstorming …`.
- Для **известных доработок** (C2–C5) — прямой промт-задание (см. примеры выше).
- Для **1С** первый шаг — встреча, а не промт агенту.
- Перед стартом любого под-проекта — **Шаг 0 (pre-flight)**.
