# Этап 7 — обмен с 1С: один экран + автосоздание по ИНН

**ТЗ:** [понятность интерфейса и закрытие функциональных пробелов](../../tz/2026-08-08-tz-usability-and-core-gaps.md), требования `У-45`…`У-59`.
**Дата:** 11.08.2026. **Статус:** ждёт подтверждения заказчика.

## 0. Коротко

Сейчас обмен с 1С разбросан по трём пунктам меню, а платежи из банковской
выписки не превращаются в организации — их приходится заводить руками по одной
строке. Этап собирает всё в один экран и включает автосоздание организаций по
ИНН, обложив его двумя страховками: обязательным предпросмотром и откатом.

**Три требования этапа уже закрыты** внеочередным хотфиксом по вашей жалобе
10.08.2026: `У-56` (колонки по заголовкам), `У-57` (не молчать без маркера),
`У-58` (блок «Что система увидела в файле») — PR #349 и #350.

## 2. Решения, которые предлагаю

### 2.1. Порядок: три PR

Этап самый крупный в программе, и в нём есть необратимое действие (создание
организаций). Дробим так, чтобы опасное ехало **после** страховок.

| PR | Что | Требования |
|---|---|---|
| **PR-1 «экран»** | Четыре вкладки, навигатор задачи, чистка меню, общая история | `У-45`…`У-48` |
| **PR-2 «страховки»** | Откат для выписки + строка предпросмотра «Будет создано организаций: N» со списком | `У-52`, `У-59` |
| **PR-3 «автосоздание»** | Создание по валидному ИНН, пометка источника, пакетное действие в очереди, переписанные стражи | `У-49`, `У-50`, `У-53`, `У-54`, `У-55` |

**Почему именно так.** ТЗ прямо требует (`У-49`), чтобы предпросмотр и откат
уехали «в том же этапе». Я предлагаю сильнее: **в более раннем PR**. Если
автосоздание поведёт себя не так, у вас уже есть чем отменить.

### 2.2. Экран (`У-45`…`У-47`)

Адрес прежний — `/{кабинет}/settings/integrations/1c`. Вкладки:

1. **Загрузка Excel** — как есть;
2. **Выписка по счёту 51** — как есть;
3. **Автообмен** — сюда переезжает содержимое `integrations/sync`;
4. **История** — новая, общая.

Корень раздела вместо редиректа показывает **навигатор задачи** — три карточки
вопросом пользователя, а не форматом файла:

- «Завести клиентов и заказы из 1С» → Загрузка Excel;
- «Разнести оплаты из банка» → Выписка 51;
- «Настроить постоянный обмен по сети» → Автообмен.

Старые адреса (`/admin/sync`, `/admin/import`, `/admin/payments-import`)
продолжают работать через `legacyHrefs` — механизм уже есть.

### 2.3. Общая история (`У-48`)

Сейчас `listImportBatches` читает одну таблицу. Делаю **единый список** с полем
«канал»: `excel` | `statement` | `auto`. Фильтры — канал, период, автор. Кнопка
отката показывается там, где откат поддержан (после PR-2 — у обоих файловых
каналов).

Батчи автообмена в списке видны, но откату не подлежат: это не файл, а поток.

### 2.4. Автосоздание (`У-49`, `У-50`, `У-54`)

Условия ровно по ТЗ: ИНН прошёл проверку контрольной суммы **и** организации с
таким ИНН ещё нет. Всё остальное — в очередь, как сейчас (`У-51`).

Компания новой организации — правило `У-50` **уже написано** в ручном пути;
переиспользую его, а не пишу заново. Если у администратора несколько компаний и
выбор не сделан — импорт отказывает кодом `company_required` (текст в словаре
ошибок есть).

Каждая созданная организация получает в аудите источник
`payment_import_auto`, а в карточке — плашку «Создана автоматически из выгрузки
1С от <дата>».

### 2.5. Стражи (`У-55`)

Тест `Т-30а` сейчас утверждает, что автосоздания быть не должно. Решение `Р-2`
это отменило, поэтому страж **переписывается** под новое правило: создаём при
валидном ИНН, отправляем в очередь при невалидном или отсутствующем. Отката
кода под старый тест не будет — это прямо запрещено ловушкой 4 в CLAUDE.md §14.

## 3. Тесты

- экран: навигатор ведёт на нужные вкладки; старые адреса редиректят; в сайдбаре
  остался один пункт;
- история: строки обоих каналов в одном списке, фильтр по каналу, кнопка отката
  только там, где откат есть;
- откат выписки на живом Postgres: платежи удалены, батч `rolled_back`, повторный
  откат отвечает `already_rolled_back`;
- автосоздание: валидный ИНН → организация создана и помечена источником;
  невалидный/пустой → очередь; существующий ИНН → организация не дублируется;
- права: обычный менеджер не может ни импортировать, ни создавать;
- пакетное создание: без показа списка не выполняется; снятая галочка исключает
  строку.

Integration-тесты на живом Postgres обязательны — этап создаёт записи.

## 4. Риски

| Риск | Что делаем |
|---|---|
| Автосоздание наплодит мусорных организаций | предпросмотр со списком (`У-52`) и откат (`У-59`) уезжают **раньше** автосоздания |
| Перенос «Автообмена» во вкладку сломает закладки | старые адреса остаются рабочими через `legacyHrefs` |
| Единая история заденет откат Excel-канала | общий список **читает**, а сам откат остаётся прежним кодом |
| Организация создастся не в той компании | правило `У-50` берётся готовым из ручного пути вместе с его тестами |
