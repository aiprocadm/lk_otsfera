# Этап 5 программы ПМ — задачи (спека)

**ТЗ:** [2026-10-13-tz-pm-review-student-manager.md](../../tz/2026-10-13-tz-pm-review-student-manager.md), §4 блок 5 (`У-299`…`У-302`).
**Решения:** `Р-ПМ-5` (схема только аддитивно), `Р-ПМ-7` (стоп снят), [NOT_DOING.md](../../NOT_DOING.md) — «отделы с подчинением».

## 1. Что есть сейчас

- Задача ([schema.prisma](../../../prisma/schema.prisma) `Task`): название, описание, срок, приоритет, колонка, привязки, повторение, исполнители (`TaskAssignee` — все равноправны), постановщик (`createdById` — хранится, но в карточке и списке не показан), чек-лист, комментарии. Результата, файлов и тегов нет.
- Форма ([task-dialog.tsx](../../../src/components/tasks/task-dialog.tsx)): поля «Каждые (раз в сколько)» и «Повторять до» видны всегда, даже при «Не повторять» (`Д-58`); исполнители — сетка флажков из всех сотрудников.
- Карточка задачи ([task-page-screen.tsx](../../../src/components/tasks/task-page-screen.tsx)): история изменений есть (журнал аудита), кнопки «Редактировать» нет — правка только с доски.

## 2. Решения этапа

| № | Решение | Причина |
|---|---|---|
| `Р-5-1` | **Соисполнитель — роль строки исполнителя**: `TaskAssignee.role` (`executor` по умолчанию, `co_executor`). Ответственный — один или несколько `executor`; соисполнители помогают, им тоже приходит «назначена задача». Права на задачу у обоих одинаковые | Аддитивно; старые строки остаются исполнителями |
| `Р-5-2` | **Постановщик** — существующий `createdById`; показывается в карточке и колонкой в списке | Поле уже есть |
| `Р-5-3` | **Результат** — `Task.result` (текст) и файлы результата `TaskResultFile` (по образцу вложений чата: проверка типа и размера, хранилище, проверка антивирусом, скачивание по временной ссылке); заполняется в карточке задачи | `У-299`; §10 правил проекта для файлов |
| `Р-5-4` | **Теги** — `Task.tags String[]` (до 10, по 30 символов), фильтр «Тег» на доске и в списке; подсказки — теги, уже встречавшиеся в задачах компании | Типизация без отдельного справочника |
| `Р-5-5` | **Поля повторения** — показываются только после выбора варианта в «Повторение» (`Д-58`) | `У-300` |
| `Р-5-6` | **Выбор исполнителя** — список с поиском по ФИО и e-mail; отдельно «Исполнители» и «Соисполнители». **Подразделений в системе нет** (отделы с подчинением — в `NOT_DOING.md`), поэтому поиск по подразделению не делается; это записано в реестре как часть `У-301` | `У-301` |
| `Р-5-7` | **«Редактировать» на странице задачи** — та же форма, что на доске; каждое изменение уже пишется в журнал (`task_updated` с «было/стало»), история на странице показывает и новые поля | `У-302` |
