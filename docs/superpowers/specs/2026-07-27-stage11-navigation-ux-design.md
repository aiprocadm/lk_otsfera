(`notifications/{core,org,partner}.ts`), без единого реестра и без русских
подписей в одном месте.

## 4. Тестовая стратегия

- Навигация: юнит на состав и группы по ролям (расширяем `navigation.cabinet.*`).
- Бейджи: сервис (счётчики по скоупу C8) + компонент (поллинг, «0 → бейдж не
  рисуется»).
- «Мой день»: сервис-агрегатор (пустые состояния, скоуп) + страница.
- Уведомления: guardrail «каждый отправляемый тип есть в реестре» — тем же
  приёмом, что `pii.capture-coverage`.
- Мобильность: рендер-тесты нижней панели и карточных списков.
- Порог покрытия 100% на изменённые слои — как во всех предыдущих этапах.
