## Остаток: ФТ-15.9 (визуальные baseline)

Существующие снимки записаны на Windows (`*-win32.png`). На Linux Playwright
создаст файлы с другим суффиксом платформы и **не заменит** существующие —
получится мусор, а не обновление. Перегенерация обязана выполняться на
платформе владельца:

```
npm run e2e:visual:update
```

Затронуты как минимум `organization-dashboard`, `organization-orders`,
`organization-documents` (новый порядок меню + нижняя панель на мобильном).
