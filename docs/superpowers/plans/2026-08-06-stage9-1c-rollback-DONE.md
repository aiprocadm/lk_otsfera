## Решения, закреплённые в коде

1. **Повторный откат `rollback_partial`-батча разрешён** (§8.2 спеки) — «добить
   хвост» после ручного разбора конфликтов; `rolled_back` — отказ. Закреплено
   integration-тестом полного цикла.
2. **«Запись удалена вручную» у `updated`-строк** — конфликт `record_missing`,
   проверяется ДО записи (не ловля P2025 в уже мёртвой PG-транзакции).
3. **Чужая компания для руководителя = `not_found`** — существование чужих
   батчей не раскрываем; руководитель без `companyId` (скоуп orgs) — `forbidden`.
4. Метки конфликтов деградируют честно: платёж без `externalId` — id, записи,
   удалённые из БД, — id; неизвестные коды UI печатает как есть.
5. Коды конфликтов — стабильные английские, русские тексты — словарь в
   компоненте (контракт §3 CLAUDE.md).
