# Этап 8 PR-3 — Договор и доп. соглашение (ФТ-9.3/9.4, завершает этап 8)

Спека: [2026-07-26-stage8-requisites-docgen-design.md](../specs/2026-07-26-stage8-requisites-docgen-design.md) §8 (подтверждена; v1 на встроенных шаблонах).
Ветка `claude/stage8-pr3-contract` (стек поверх PR-2 #240).

## A. Модель (миграция)

- [x] `DocumentCounter`: PK → `@@id([companyId, year, kind])`, `kind String
      @default("invoice")` — раздельные последовательности счетов и договоров
      (таблица введена в PR-2 и в проде пуста, смена PK безопасна).

## B. Генерация

- [x] `generate.ts`: `docType` + `contract | extra_agreement`.
      Нумерация по решению заказчика (зеркало пары счёт→акт):
      договор — свой счётчик `kind='contract'` → «Д-{год}-{N}»;
      доп. соглашение наследует номер договора → «ДС-{год}-{N}»
      (без договора → `contract_required`).
- [x] `contractDocumentPdf.ts` — шаблон договора/допсоглашения: преамбула
      («Исполнитель… Заказчик… заключили настоящий договор»), предмет
      (позиции/название заказа), цена и порядок расчётов (сумма, НДС),
      сроки, ответственность, реквизиты сторон блоками, подписи.
      Допсоглашение — ссылка на договор + изменяемые условия (сумма/предмет).
- [x] Русские подписи ошибок (`contract_required`) в панели.

## C. UI

- [x] Панель «Сформировать документы»: кнопки «Договор» и «Доп. соглашение»
      (последняя disabled без договора, как акт без счёта); проп
      `hasContract` со страницы заказа.
