## Главное решение этапа

`У-62` оказалось требованием **про права, а не про вёрстку**: сервис реквизитов
пускал только пользователей организации. Принадлежность организации портфелю
проверяется **по базе** (`Organization.partnerId`), а не по сессии — список
организаций в токене устаревает, привязка к партнёру нет. Запись разрешена
только `partnerRole === 'admin'`, чтение — любому партнёрскому пользователю с
доступом.

## Грабли

1. **Вложенные async-подкомпоненты, объявленные внутри серверной страницы, не
   отрисовываются** хелпером `renderServerComponent` — контейнер приходит
   пустым, тесты «видят» пустой экран. Лечение: грузить данные в самой странице
   и держать JSX плоским.
2. Переезд «Команды» уронил четыре теста меню, ожидавших пункт и его
   `partnerAdminOnly`.
3. **Владелец снова влил спековый PR во время реализации** (второй раз за
   программу) — ветку удалили, код пришлось отправлять отдельным PR от `main`.
   Проверка `gh pr view <N> --json state` перед пушем себя оправдала.
