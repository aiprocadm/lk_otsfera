**Правило на всю программу:** порог в `vitest.config.ts` — нижняя планка. После
каждой фазы он поднимается на достигнутый уровень, чтобы результат нельзя было
откатить незаметно.

**Как мерить.** Полный прогон `npm run test:coverage` — ~30 минут, гоняем **один
раз на фазу**. Внутри фазы — адресно: `npx vitest run --coverage <файлы>`
показывает непокрытые строки конкретного файла без полного прогона.
**Смотреть все четыре метрики, включая functions** — в этой сессии проверка
только по statements/branches уже дала ложное «покрыто».

## Принципы (из §4 спеки, держать в голове на каждом шаге)

1. Тест пишется под **поведение**, а не под строчку.
2. Недостижимый код **удаляется**, а не «покрывается».
3. `v8 ignore` — только с причиной в комментарии, и все они попадают в close-out.
4. Найденный дефект чинится сразу, отдельным коммитом с описанием (решение Q4).
