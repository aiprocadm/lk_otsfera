**Последняя часть этапа 1.** Заказчик выбрал (Q3) отдельную страницу документа,
поэтому объём — не только секция полей, но и сам экран: до этого документ жил
исключительно строкой в списке.

## Задачи

### 1. Сервис карточки

- [x] `lib/services/documents/detail.ts` — `getDocumentDetail(prisma, session, id)`.
- [x] Доступ **не изобретается**: тот же `canReadDocument`, что и у роута
      скачивания (§4 CLAUDE.md).
- [x] Отказ и отсутствие записи дают **одинаковый** `not_found` — иначе по коду
      ответа перебором узнаётся, какие id существуют.
- [x] Имя контрагента подтягивается из организации/партнёра; удалённый
      контрагент не роняет карточку.

### 2. Экран

- [x] `components/documents/document-detail-view.tsx` — сведения (номер, версия,
      размер, формат, подпись, кто загрузил, контрагент, заказ, статус
      антивируса) + кнопка скачивания + слот для секции полей.
- [x] Файл отдаётся **только presigned-ссылкой** через существующий роут
      (§10 CLAUDE.md): приложение файл не проксирует.
- [x] Заражённый файл: карточка открывается, кнопки скачивания нет,
      показывается предупреждение с причиной. 410 от роута трактуется отдельным
      сообщением — это не «не найдено».

### 3. Страницы (четыре кабинета)

- [x] `/admin/documents/[id]`, `/manager/documents/[id]`,
      `/partner/documents/[id]`, `/organization/documents/[id]`
      (последняя — внутри `OrgAppShell`).
- [x] **Руководителю отдельной страницы нет намеренно:** роль у него `manager`,
      префикс `/manager` открыт (§4 CLAUDE.md), список документов там же.
      Спека называла «пять кабинетов» — это уточнение по факту устройства ролей.
- [x] Ссылки на карточку из всех четырёх списков (`cardHrefBase` у
      `DocumentsList`; без пропа имя остаётся текстом — портфель партнёра
      карточки не имеет).
- [x] Секция настраиваемых полей документа на карточке.

### 4. Чистка, всплывшая по ходу

- [x] `getFieldsForEntity` — обёртка «сразу массив полей» в сервисе. Ветка
      «сервис отказал» была скопирована в девять карточек и в каждой требовала
      своего теста; теперь живёт в одном месте.

### 5. Тесты

- [x] Сервис: not_found для чужого и несуществующего, контрагент организации и
      партнёра, удалённые контрагенты, имя/почта/пусто у загрузившего,
      заражённый файл.
- [x] Компонент: сведения, прочерки, статусы антивируса, ссылки в свой кабинет,
      скачивание (успех, 410, прочая ошибка), заражённый файл.
- [x] Страницы: гард каждого кабинета, `notFound()` при отказе, ссылки не
      уводят в чужой кабинет.
- [x] Список: имя-ссылка при `cardHrefBase` и текст без него.
- [x] 100 % покрытие новых файлов (§6 CLAUDE.md).
