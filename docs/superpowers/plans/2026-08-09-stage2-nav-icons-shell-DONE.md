## Отличия от плана

1. **Три конфликта значков всплыли уже при раскладке**, их не было в спеке:
   `🤝` занят «Сделками», `👥` — «Сотрудниками», `👤` — «Пользователями».
   Отсюда «Партнёры» → `🏬`, «Команда» → `👔`, «Кабинет слушателя» → `🎒`.
2. **Два каркаса оставлены тонкими переходниками, а не удалены**:
   `org-app-shell`/`org-sidebar` (у org-кабинета нет общего layout-шелла —
   активная организация резолвится из `searchParams`, поэтому все 17 страниц
   оборачивают себя сами) и `dashboard/app-shell` (у `/student` две ветки входа).
3. **Структура шапки партнёра стала как у остальных** (сайдбар во всю высоту,
   шапка над контентом). Цвет остался тёмным — как договаривались.

## Грабли

1. **Новые `layout.tsx` падали с `React is not defined`.** В этом репозитории
   React импортируют **явно**; автоматического JSX-рантайма в vitest нет.
2. **Переименования уронили 7 тестовых файлов.** Отдельно — тест партнёрского
   шелла: он не мокал `usePathname`, который теперь нужен общему сайдбару.
3. **`react/no-children-prop`**: в `.tsx`-тесте нельзя передавать `children`
   пропом в `React.createElement` — переписано на JSX.
4. **Владелец влил спековый PR #334 во время реализации**, GitHub удалил ветку,
   и `git push` молча создал её заново — код оказался вне какого-либо PR.
   Обнаружено по строке «`* [new branch]`» в выводе push. Лечение: перед
   отправкой продолжения проверять `gh pr view <N> --json state`; при `MERGED`
   открывать новый PR от `main`.
