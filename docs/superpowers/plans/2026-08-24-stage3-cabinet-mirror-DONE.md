## Что нашлось по дороге — то, чего в ТЗ не было

Требования описывали расхождения в меню. При реализации вскрылись **настоящие
поломки**, каждая починена в своём PR:

- **`Д-33`** — вкладки «Обмена с 1С» у руководителя отдавали 404 (#421).
- **`Д-34`** — роль «Руководитель» заводилась только через «пригласить
  менеджером → повысить»; фильтров по роли и компании не было (#422).
- **Приглашённый сотрудник ЦО заводился без компании** (#422) и попадал в
  пустой кабинет: скоупы деньги-заказы-документы при пустом `companyId`
  честно закрывают всё, и человек видел шесть пустых разделов без объяснения.
  Добавлен код `company_required`, русская строка и обязательный выбор
  компании.
- **`Д-40`** — нижняя панель на телефоне схлопывалась (#425). Список был на
  адресах, а половина пунктов сидит под возможностями, выключенными по
  умолчанию: у менеджера оставались **две** вкладки из четырёх.
- **Порядок «Заявок на обучение» у администратора** (#427) — стояли перед
  «Организациями», у менеджера и руководителя после. Нашёл сам страж
  зеркальности; выровнено, а не записано в исключения.

## Уроки, которые стоят отдельной строки

**Зелёный страж ничего не доказывает.** Мутации ловили пустые проверки
**четыре раза за этап**:

- страж названий искал `label:` с начала строки и пропускал однострочный пункт
  меню — самый вероятный вид регресса (#417);
- страж крошек совпадал со словом `breadcrumbs` где угодно в файле, включая
  осиротевший импорт (#421);
- у фильтра ролей не было теста, что он вообще доходит до сервиса (#422);
- страж редиректа искал слово `permanentRedirect`, а `redirect as
  permanentRedirect` его содержит — то есть «временный редирект вместо
  постоянного» не ловился (#426).

**Мутацию надо проверять по факту.** `python .replace()` молча ничего не
делает, если строка не совпала: первая «мутация» этапа просто не применилась,
а тест «прошёл».

**Сплошная замена задевает чужое.** Переименование `dealId` → `orderId` в
#426 добралось до настоящего домена `Deal` (воронка продаж) — 22 файла
откачено. У стража теперь есть обратная половина: он падает, если воронку
переименуют «заодно». Тот же sed испортил и документы («`/partner/orders` →
`/partner/orders`»), и `npx prettier --write "src/**"` переформатировал 90
посторонних файлов.

**Проп, который остался без вызывающих, надо удалять, а не оставлять.** Тёмная
тема каркаса (#427) осталась ровно у одного кабинета и была убрана целиком:
пока проп жив, шапка разъезжается обратно одной строкой — и гейт покрытия
100 % красит мёртвую ветку в красный.

## Приёмка

- `npm run typecheck`, `npm run lint`, `npm run test:unit` — зелёные на каждом
  из одиннадцати PR.
- Каждый страж этапа проверен мутациями: от трёх до семи на PR.
- `AUDIT.md`: `У-106`…`У-121` — все `✅`, дата 26.08.2026.
- Правило зеркала (`У-121`) с этого этапа держится **механически**: незаписанное
  расхождение реестров пар кабинетов роняет сборку.
