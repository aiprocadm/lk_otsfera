## Гочи для будущих сессий

- Postgres живёт в **WSL Ubuntu** и умирает вместе с idle-shutdown WSL → «Can't reach database server at localhost:5432» посреди работы. Лечение: разбудить WSL любой командой (postgres автостартует) + держать `wsl -e sleep 14400` в фоне.
- Preview-вкладка в фоне не отрисовывает Suspense-swap (вечный скелетон/пустой body) — проверять контент через `fetch(url).then(r=>r.text())`, это не баг приложения.
