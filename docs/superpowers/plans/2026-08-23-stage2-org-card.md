# Этап 2 — единая карточка организации и сотрудники во вкладке — план работ

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development или superpowers:executing-plans; шаги — чекбоксы `- [ ]`.

**Спека:** [2026-08-23-stage2-org-card-design.md](../specs/2026-08-23-stage2-org-card-design.md) ✅ подтверждена 23.08.2026 (мерж [#407](https://github.com/aiprocadm/lk_otsfera/pull/407); вопросы §5 — по умолчаниям: партнёру «Оплат» нет, `/manager/students` остаётся скрытым поиском без пункта меню, порядок PR принят).

**Порядок PR отличается от спеки.** Спека делила этап на три PR; при
реализации второй оказался слишком большим (вкладка «Сотрудники», карточка
сотрудника, полная вкладка «Настройки», снятие пункта меню и правка «частых
задач» — пять разных экранов). Он разделён на три отдельных PR, чтобы каждый
можно было прочитать и откатить целиком. Состав требований не менялся.

Порядковое ограничение §5 ТЗ: `У-100` (снятие пунктов меню заказчика) — только
после `У-97` (вкладка «Сотрудники» работает). Поэтому PR-5 идёт последним.
