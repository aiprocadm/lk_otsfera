## Отличия от плана

Отдельных файлов `*-card-list.tsx` на каждую таблицу заводить не стали:
карточный вид живёт **в том же файле**, что и таблица, рядом с ней. Так кнопки
действий физически одни и те же (общая функция), и два вида не могут разъехаться
при следующей правке — ради этого требование и вводилось.

## Попутно закрытое расхождение

Партнёрская нижняя панель писала «Мои заявки» после переименований этапа 2 —
подписи были захардкожены. Теперь состав панели приходит из общего реестра, и
такое расхождение невозможно по построению.

## Грабли

1. **Пропы-функции не проходят границу сервер→клиент.** Панель принимает
   готовую разметку; закрытие по выбору пункта ловится делегированием клика по
   `<a>`; `?org=` для вкладок передаётся строкой `tabQuery`, а не функцией.
2. **Карточки и таблица лежат в DOM одновременно** (прячет CSS) — семь
   существующих тестов начали находить по два элемента. Чинилось точечными
   `getAllBy…[0]`, проверки не ослаблялись.
3. **`mobileTabsFor` падал на неизвестной роли** — вскрыл тест партнёрского
   шелла. Добавлен `?? []`: старый токен с незнакомой ролью не должен ронять
   весь кабинет.
4. **`cd` в bash-команде сохраняется между вызовами** — прогон vitest ушёл из
   корня репозитория и подхватил чужой include-список.
