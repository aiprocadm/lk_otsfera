## Финальное ревью поймало (исправлено до мержа)

- 🔴 **CRITICAL IDOR**: `attachmentPath` принимался из тела `POST /api/messages` как произвольная строка → download-роут выдавал signed URL на **любой** файл bucket'а `documents` (включая документы заказов). Пропущено 13 по-задачными ревью — поймано сквозным проходом. **Фикс:** `sendMessage` требует префикс `chat/<orderId>/`; download требует `chat/`. Двухслойно, с тестами атаки.
- Утечка сырого storage-path в JSON (`listMessages` → `hasAttachment`); `UnreadBadge` поллил при выключенном флаге; невалидный `after`-курсор.

## Отложено в v1.1 (задокументировано, не тихие пробелы)

## Гочи для будущего

- **Локальный «посмотреть»:** нужен `FEATURE_CHAT=1` (через `.env.local`) + засеянный чат-тред. `npm run prisma:seed` падает на `ECONNREFUSED :6379` (Redis нет на этой Windows-машине), но частичных данных + прямого посева треда хватает; текстовый чат Redis не требует. Headless-preview **не завершает** клиентскую подмену React-Suspense-стрима — смотреть в обычном браузере.
- Multi-line `npx tsx -e "..."` через bash не отдаёт stdout — выноси скрипт в файл.
- Среди сессии chat-миграции вдруг показались неприменёнными (`migrate deploy` вернул их; причина — посторонний reset). Если `OrderThread` «не существует» — прогнать `prisma migrate deploy`.
