законченная тема, крошки ближе к навигации по цепочке.

## Задачи

### 1. Сервис-агрегатор «Мой день» (ФТ-15.3)

- [x] `services/manager/myDay.ts` — один вызов, всё существующими скоупами
      (новых правил видимости не появляется):
      - задачи **на сегодня** и **просроченные** — `taskFiltersWhere` (мои);
      - **Поступило** — `countIntake` (тот же union, что у бейджа);
      - **Готово к передаче** — чек-лист закрыт и передача не нажата
        (решение заказчика §5-2);
      - **мои сделки по стадиям** — `dealScopeWhere` + группировка;
      - **свежие обращения** и **пропущенные звонки** за сутки —
        `intakeInboundWhere` / `intakeCallWhere`.
- [x] Пустые состояния — честные нули, карточка не исчезает (ФТ-15.8).

### 2. «Готово к передаче» без дублирования логики

- [x] `orderDelivery.ts`: выделить **пакетную** `evaluateReadinessBatch`
      (одна выборка статусов сканов на пачку заказов) и переиспользовать её в
      `getOrderReadiness`/`deliverOrderResult` — чтобы «Мой день» считал
      готовность **той же** функцией, а не своей копией.
- [x] `READINESS_SELECT` экспортируется — «Мой день» берёт ровно те же поля.
- [x] Отменённые заказы в подсчёт не идут (передавать нечего).

### 3. UI «Мой день»
