## Найдено по ходу

- **Якорь намеренно не принимается из формы.** Роут отбрасывает `anchor` из
  тела запроса: события раздаёт система, иначе заказчик мог бы привязать к
  оплате произвольный статус и сломать автоперевод. Закреплено тестом роута.
- **Перестановка — два запроса, и второй может упасть.** Если упал первый,
  второго не будет вовсе (иначе порядок разъедется); если упал второй, успех не
  показываем. Обе ветки под тестами.
- **Счётчики пунктов меню снова пришлось править** в четырёх чужих тестах
  (канон админа и руководителя, оба сайдбара). Это третий раз за программу —
  жёсткие числа в тестах меню ломаются от любого нового пункта.
