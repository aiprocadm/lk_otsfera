## Ключевые решения

- **Приоритет «база → env → умолчание»** везде; значения читаются **на каждый
  вызов**, не при загрузке модуля (модульная константа подхватила бы правку
  только после перезапуска).
- **`envVar: null`** для настроек, которые раньше были константами кода:
  выдуманное имя переменной сбило бы стражи `У-122`/`У-134`.
- **Стражи env включены последним PR** (требование самого ТЗ) — и выводят
  fallback'и механически из `SETTING_SPECS`/`FEATURE_FLAGS`: переезд новой
  переменной не требует править стражи.
- **Ultracode с PR-8**: перед PR гонялось адверсариальное ревью дифа
  (34 агента, 4 линзы × 2 скептика); все 4 уникальных дефекта PR-8 нашло
  именно оно. Хотфикс #437 сделан workflow из 10 параллельных агентов.

## Уроки (полные версии — в плане, по PR)

1. Зелёный страж ничего не доказывает — **13 мутаций** на PR-8, **5** на
   PR-9, слабые проверки чинились по мутациям (4-й этап подряд).
2. Гейт, который физически не запускается, хуже отсутствующего: `depcruise`
   не было в `node_modules`, CI выключен → 10 нарушителей границ скопились
   молча. Юнит-страж-замена гоняется всегда.
3. Страж действий обязан вырезать комментарии и видеть обе формы экспорта —
   иначе «закомментировали гард» остаётся зелёным.
4. `.env.example` без стража врёт уже через месяц: 33 недокументированные
   переменные и строка флага, удалённого две недели назад.
