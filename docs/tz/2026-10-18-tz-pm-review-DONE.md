## Уроки

1. **Сухой прогон на настоящем стенде находит то, чего не видит ни один тест.** Перенаправления за посредником уводили на `https://localhost:3000/…` (#713): юнит-тесты передавали адрес `https://app.local`, а Next.js за nginx знает себя как `localhost`. Проверено только запуском собранного приложения с шапками посредника.
2. **Тесты с `new PrismaClient(` живут в слое живой базы, даже если про server-actions.** Меняя адрес или текст, искать его по всему `src/__tests__`, а не по слою (№44).
3. **Новые тесты — с проверкой типов тестового проекта** (`tsc -p src/__tests__`): vitest типы не проверяет, а полный прогон их проверяет (этап 7, PR-2).
4. **Первый запуск нового живого теста с неполной уборкой оставляет мусор**, о который спотыкаются соседние тесты (чистят «тестовых» пользователей и упираются в их журнал). Уборку писать сразу полной, мусор — вычищать.
5. **Прежние требования — часть контракта.** Сужение очереди по `У-318` чуть не выкинуло вопросы из кабинета (ФТ-11.1); прежде чем убирать — искать, кто это обещал.
