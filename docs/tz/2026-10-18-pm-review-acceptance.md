## 3. Что ждёт владельца

1. **Проход ПМ по чек-листу** (`У-319`) — акт приёмки, его может сделать только человек.
2. **Ключ почтового провайдера стенда** (`У-271`): без него приглашения и восстановление пароля честно пишут «письмо не отправлено», но не уходят.
3. **`nodemailer` 10** — три записи `npm audit` (через `imapflow` и `mailparser`): исправление есть только в новой крупной версии; по правилу `С-9` и решению `Р-26` это спека, а не хотфикс.
4. **Статус заказов из 1С.** У заказа, пришедшего из обмена, шапка говорит «Завершён, оплачен», а панель статуса — «Черновик заявки»: автоперевод статуса по фактам (`applyStatusAnchor`) в рабочем коде не вызывается (отмечено ещё в спеке этапа 6). Вопрос: переводить ли такие заказы на «Заказ закрыт» по данным 1С.
