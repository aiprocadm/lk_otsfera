Этот файл читается первым по фразе «продолжай по ТЗ» (протокол — CLAUDE.md §14). Правила ведения:

- **Текущий этап** — первый со статусом не `✅ готов`. Этапы выполняются строго последовательно (§11 ТЗ), не перескакивать.
