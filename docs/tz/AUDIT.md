# Реестр сверки кода с ТЗ (drift-аудит)

Код и ТЗ расходятся молча: требование отгружено, потом соседний PR меняет
поведение, и через месяц система работает не так, как написано в документе,
хотя все гейты зелёные. Этот файл — единственное место, где записано, **что
проверено, чем именно и с каким результатом**.

Протокол — [CLAUDE.md §16](../../CLAUDE.md). Прогресс по этапам — [STATUS.md](STATUS.md).
Действующее ТЗ — [2026-08-08-tz-usability-and-core-gaps.md](2026-08-08-tz-usability-and-core-gaps.md).

## Как пользоваться

**Когда сверять:** в начале этапа (по его требованиям) · перед PR этапа
(обязательно, §14 шаг 5) · по фразе заказчика «сверь код с ТЗ» / «проверь
логику по ТЗ» (**полный проход по всем `У-N`**) · при закрытии программы.

**Как сверять.** Найти файл-якорь недостаточно. Наличие функции не значит, что
её вызывают; кнопка в UI не значит, что сервер запрещает обход. Проверяется
**наблюдаемое поведение** — колонка «Что проверять» в таблицах ниже написана
именно так, чтобы её можно было выполнить, а не «посмотреть код».

**Вердикты:**

| Вердикт | Что означает | Что делать |
|---|---|---|
| `✅` | Поведение совпало с требованием, проверено вручную или тестом | Записать якорь и дату сверки |
| `⏳ этап N` | Требование ещё не наступило по плану §5 ТЗ | **Не трогать вне очереди** — порядковые ограничения важнее желания «сделать заодно» |
| `❌` | Требование уже отгруженного этапа нарушено кодом | **Чинить** — это дефект, а не новый объём. Обязателен тест-страж на само расхождение |
| `⚠` | Проблема настоящая, но ни одного `У-N` под неё нет | **Не чинить молча.** Записать в раздел «Вне объёма» и спросить заказчика |

**Правило для `❌`:** если файл и так трогает текущий этап — правкой в его PR;
иначе — отдельным маленьким хотфикс-PR от `main`. Без теста-стража расхождение
вернётся следующим PR — фиксация без стража не считается закрытием.

**Чего сверка не даёт права делать:** переписывать требование под текущий код
(«в коде так — значит, ТЗ устарело»), расширять объём под видом исправления,
ослаблять гейты (`CLAUDE.md` §6) ради зелёной сборки.
