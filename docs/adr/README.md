# ADR — журнал архитектурных решений

ADR (Architecture Decision Record) — короткая запись одного значимого решения:
почему выбрали так, а не иначе, и что из этого следует. ADR не редактируются задним
числом: если решение развернулось — пишется **новый** ADR, старый помечается
«заменён ADR NNNN».

## Правила

1. Формат файла: `NNNN-slug.md` — заголовок, Статус (принято, дата), Контекст,
   Решение, Последствия, Источники (ссылки на ТЗ/спеки/код). Компактно, 10–20 строк.
2. **Новый разворот решения = новый ADR + строка в [§23 ТЗ](../tz/2026-07-29-tz-lk-otsfera-v0.5.md)**
   (журнал разворотов) + строка в индексе ниже.
3. ADR фиксирует только **фактически принятые** решения (подтверждённые заказчиком
   или закреплённые в коде/ТЗ), не предложения.
