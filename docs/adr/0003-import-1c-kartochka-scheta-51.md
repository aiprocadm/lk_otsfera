# ADR 0003: Формат импорта из 1С — Excel «Карточка счёта 51»

**Статус:** принято, 2026-07-29 (разворот требования v0.4; формат подтверждён на реальной выгрузке).

## Контекст

ТЗ v0.4 (§7.2) предполагало импорт оплат в формате `1CClientBankExchange`, но реальный
файл заказчик не предоставил. 29.07.2026 формат подтверждён на живой выгрузке из 1С.

## Решение

Целевой формат импорта — Excel-отчёт 1С **«Карточка счёта 51»** (расчётный счёт), а не
`1CClientBankExchange`. Правила разбора: платёж клиента = «Поступление» с корр-счётом 62
(62.01 постоплата / 62.02 аванс); возврат = «Списание» с корр-счётом 62; корр. 60/91 и
внутренние переводы исключаются. Ключ дедупликации — номер документа 1С.

## Последствия

- Несопоставленные платежи идут в очередь ручного сопоставления; повторный импорт не дублирует платёж.
- Исходный файл сохраняется, ведётся журнал загрузок.
