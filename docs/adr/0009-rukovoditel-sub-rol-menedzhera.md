# ADR 0009: Руководитель — суб-роль менеджера, не отдельная top-level роль

**Статус:** принято, 2026-06-05 (спека C8); выделение в самостоятельную роль отложено заказчиком 2026-07-29.

## Контекст

Руководителю нужны полномочия над менеджерами (флип видимости, ростер, ставки), но
заведение седьмой top-level роли трогает enum `Role`, JWT, `protectedPrefixes`, логин,
меню, воркеры и десятки гардов.

## Решение

Руководитель = `role='manager'` + **`managerRole='leader'`** в JWT (гард
`requireManagerLeader`); работает company-wide в границах C8. Не путать с
`roleInOrg='leader'` — старшим в организации. Выделение в самостоятельную роль
**отложено решением заказчика** до отдельной программы: `managerRole` знают ~36 файлов
кода и ~110 тестов, мест `role === 'manager'` — 83; пропуск любого либо закроет
руководителю нужное, либо откроет менеджеру лишнее.

## Последствия

- Каждое правило «для менеджера» обязано явно решить, распространяется ли на руководителя (грабля PR #273 — карточка организации).
- Возврат к выделению — только по явной просьбе заказчика, через спеку (черновик есть).
