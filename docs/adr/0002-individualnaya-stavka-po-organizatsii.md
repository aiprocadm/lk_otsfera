# ADR 0002: Индивидуальная ставка комиссии по организации (override)

**Статус:** принято, 2026-06-26 (разворот требования v0.4).

## Контекст

ТЗ v0.4 (§9.1) допускало ставку комиссии только на уровне партнёра целиком. Заказчику
понадобились договорные скидки по отдельным организациям.

## Решение

Поверх базовой ставки партнёра допускается **индивидуальная ставка по конкретной
организации** (override). Приоритет резолвинга на дату платежа:
`override организации` → `историческая ставка партнёра` → `дефолтная ставка партнёра`.
Cross-partner gate: override чужой организации не протекает на другого партнёра.

## Последствия

- Обе ставки историчны (таймлайны `CommissionRateChange` / `OrganizationCommissionRateChange`); резолвинг — чистые функции без БД.
- Очистка override = событие истории (`newRate: null`), возврат к наследованию уровня партнёра.
