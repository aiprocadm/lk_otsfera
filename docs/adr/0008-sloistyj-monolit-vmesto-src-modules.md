# ADR 0008: Слоистый модульный монолит вместо `src/modules/*`

**Статус:** принято, 2026-07-31 (решение заказчика, фаза 3 программы «эталонный репозиторий»).

## Контекст

Программа качества рассматривала перекладку кода в фича-модули (`src/modules/<домен>/`).
Заказчик решил узаконить **фактическую слоистую архитектуру** — перекладка сотен файлов
не давала пользы, ломала git-историю и открытые ветки.

## Решение

Архитектура остаётся слоистой: `app → server-actions → services → lib`; `worker` —
отдельный процесс поверх services/lib; `components` — презентационный слой без базы.
Границы защищены **механически**: dependency-cruiser запрещает циклы, импорты «вверх»
из `lib/**`, базу из `components/**`, UI из `worker/**`, `mock-1c` из `src/**`.
Проверка `npm run boundaries` входит в `verify` и CI; нарушение = красная сборка.

## Последствия

- Домен выражается папками внутри слоя (`services/commission/`), а не вертикальным модулем.
- Типы, нужные и lib, и компоненту, живут в lib (компонент реэкспортирует).
