# Глоссарий lk-otsfera

Единый словарь терминов личного кабинета. На него ссылается ТЗ (ФТ-15.8):
**user-facing строки пишутся терминами отсюда**. Если для понятия появляется
второе название — сначала правим глоссарий, потом интерфейс.

Слева — то, что видит пользователь; справа — как это называется в коде и в базе.
Расхождения намеренные: интерфейс говорит по-русски, коды и роуты — по-английски
и не переименовываются ради косметики (это осиротило бы исторические данные).

## Термины, которые чаще всего путают

| В интерфейсе | В коде | Что это на самом деле |
|---|---|---|
| **Мои заявки** | `ClientRequest`, `/partner/requests`, `/organization/requests` | Обращение клиента в поддержку: вопрос, запрос расчёта, новая потребность. **Не** про конкретных слушателей |
| **Заявка на обучение** | `EnrollmentRequest`, `/*/enrollments` | Список слушателей, которых надо обучить: ФИО, направление, даты |
| **Обращения клиентов** (у сотрудников) | `ClientRequest` | Тот же объект, что «Мои заявки», но в кабинете сотрудника — очередь на разбор |
| **Входящие в работу** | Intake (`services/intake`) | Сводная очередь из четырёх источников: заявки, заявки на обучение, обращения из каналов, звонки |

Правило простыми словами: **«Мои заявки» — это разговор, «Заявка на обучение» —
это список людей.**

## Сквозной поток продажи

| В интерфейсе | В коде | Смысл |
|---|---|---|
| Заявка (обращение) | `ClientRequest` | Клиент написал сам |
| Лид | `Lead` | Внутренняя карточка потенциальной продажи. **Клиенту не показывается** (§3.2 ТЗ) |
| Сделка | `Deal` | Переговоры со стадиями на канбан-доске |
| Заказ | `Order` | Обязательство выполнить работу; появляется при выигрыше сделки |
| Позиция заказа | `OrderItem` | Один слушатель × одно направление |

## Заказ и его завершение

| В интерфейсе | В коде | Смысл |
|---|---|---|
| Готовность к передаче | `evaluateOrderReadiness` | Чек-лист: всё ли готово отдать клиенту |
| Результат передан | `Order.resultDeliveredAt` | Менеджер нажал «Передать результат»; ставится один раз |
| Работа согласована | `Order.deliverablesApprovedAt` | Отметка менеджера для заказов на разработку документов |
| Удостоверение | `Certificate` | Документ об обучении слушателя |
| Скан удостоверения | `Certificate.documentId` | Файл удостоверения, привязанный к записи |

## Люди и организации

| В интерфейсе | В коде | Смысл |
|---|---|---|
| Организация | `Organization` | Компания-клиент |
| Сотрудник (организации) | `Student` | Физлицо, которое учится. Слово «слушатель» — синоним в учебном контексте |
| Партнёр | `Partner` | Посредник, приводящий организации |
| Менеджер | роль `manager` | Сотрудник, ведущий заказы |
| Руководитель | `managerRole='leader'` | Менеджер с расширенной видимостью по компании |

## Документы и деньги

| В интерфейсе | В коде | Смысл |
|---|---|---|
| Счёт · Акт · Договор · Доп. соглашение | `Document.type` | Оперативные документы платформы. Бухгалтерский канон — в 1С |
| Комиссия | `CommissionStatement` | Вознаграждение партнёра за период |
| Задолженность | `Order.totalAmount − paidAmount` | Сколько ещё не оплачено |
